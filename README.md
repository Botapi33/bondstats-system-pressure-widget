# BondStats System Pressure Index Widget

Compact live homepage widget for the BondStats System Pressure Index.

## Deploy
1. Create a GitHub repository named `bondstats-system-pressure-widget`.
2. Upload `index.html` to the repository root.
3. Enable GitHub Pages: **Settings → Pages → Deploy from branch → main → /(root)**.
4. Embed the resulting GitHub Pages URL in Google Sites.

## Recommended Google Sites embed
- Desktop width: 100%
- Height: 340–380 px
- Mobile: responsive iframe; the widget collapses to a single-column layout automatically.

## Data
Uses the live BondStats Global Yields JSON and exactly the same fixed System Pressure Index methodology as the full index.

The widget refreshes automatically every 15 minutes and links to the full System Pressure Index.
